SIS SPECIAL WEBSITE ❤️

Run locally:
1. Extract the ZIP.
2. Open the Sis_Special_Website folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server" if you have the Live Server extension.
   OR simply double-click index.html to open it in your browser.

No Node.js, npm, or extra libraries are required.

To customize:
- Edit the Bengali paragraphs in index.html.
- The title can be changed in the <title> tag.
- Colors and layout are in the <style> section.
